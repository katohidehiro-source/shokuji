# 食事きろく（試作版 v1.0）導入手順

写真から料理名・カロリー・PFC・塩分をAIで推定して記録する、スマホ用のWebアプリ（PWA）です。
PCへのインストールは不要。費用は0円から始められます。

## 構成

| 項目 | 内容 |
|---|---|
| アプリ | HTML / CSS / JavaScript のみ（サーバー不要） |
| 置き場所 | GitHub Pages（無料） |
| データ | 各スマホのブラウザ内（IndexedDB）。外部には送りません |
| AI | 設定画面で Gemini / OpenAI / Claude を切り替え。写真はAI会社にだけ送られます |
| APIキー | 各スマホの中にだけ保存。コードには含まれません |

## 1. 公開（PCのブラウザだけで約10分）

1. https://github.com でアカウントを作成（無料）
2. 右上「＋」→「New repository」
   - Repository name: 例 `shokuji`（家族以外に知られたくなければ推測しにくい名前に）
   - **Public** を選択（無料プランのGitHub Pagesは公開リポジトリが必要）→「Create repository」
3. 「uploading an existing file」をクリック → zipを展開した **中身のファイルとiconsフォルダ** をドラッグ＆ドロップ →「Commit changes」
   - `index.html` がリポジトリの一番上に来るようにします
4. 「Settings」→ 左メニュー「Pages」→ Branch を `main` / `(root)` にして「Save」
5. 1〜2分後、`https://<ユーザー名>.github.io/shokuji/` で開けます

> コードが公開されても問題はありません。記録とAPIキーは各スマホの中だけにあり、他人がURLを開いても空のアプリが表示されるだけです。
> URL自体を家族だけに限定したい場合は、Cloudflare Pages ＋ Cloudflare Access（無料枠）に置き換えられます。

## 2. スマホに入れる

- **iPhone**: **Safari** でURLを開く → 共有ボタン →「ホーム画面に追加」
- **Android**: **Chrome** でURLを開く → メニュー「⋮」→「ホーム画面に追加」（または「アプリをインストール」）

以後は **必ずホーム画面のアイコンから** 開いてください（iPhoneはSafariで開いた場合と保存領域が別になります）。

## 3. AIのAPIキーを設定

アプリの「設定」タブ → AIを選び → APIキーを貼り付け →「接続テスト」

| AI | キーの発行先 | 費用 |
|---|---|---|
| Gemini（おすすめの初期設定） | https://aistudio.google.com →「Get API key」 | 無料枠あり（回数上限あり。無料枠では送信内容がGoogleの改善に使われる場合あり） |
| OpenAI | https://platform.openai.com → API keys | 従量課金（前払い） |
| Claude | https://console.anthropic.com → API Keys | 従量課金（前払い）。Claudeのチームプラン等とは別契約 |

- モデル名は初期値のままで動く想定です。エラーになる場合は「モデル一覧を取得」を押し、モデル名欄から選び直してください。
- 課金する場合は、各社の管理画面で **月の利用上限** を設定しておくと安心です。
- 家族で同じキーを共有して使えます（各自のスマホで入力）。

### 3-1. Gemini のAPIキーを取得する（無料・約5分）

PCのブラウザで行うと楽です（スマホでも可）。

1. https://aistudio.google.com を開き、**個人のGoogleアカウント（Gmail）** でログイン
   - 会社のGoogleアカウントは管理者設定で使えないことがあります。
2. 初回は利用規約の画面が出るので、内容を確認して同意
3. 画面左下（またはメニュー）の **「Get API key」** をクリック
4. **「Create API key」**（APIキーを作成）をクリック
   - プロジェクトを聞かれたら、既定のプロジェクトを選ぶか新規作成します（名前は何でも可、例: `shokuji`）
5. 表示されたキー（文字列）を **コピー**
   - 最近発行されるキーは `AQ.` で始まります（以前の `AIza…` 形式も引き続き使えます）。どちらでもこのアプリで使えます。
6. スマホのアプリ →「設定」→ **Gemini** を選択 → 「APIキー」欄に貼り付け →「接続テスト」
   - 「接続OK」と出れば完了。スマホへは、自分宛てのメールやLINEのKeepメモ等で送ると楽です（送った後はそのメッセージを削除）。

**無料のまま使うための注意**

- AI Studio で **お支払い情報（請求先アカウント）を登録しなければ無料枠のまま** です。上限を超えるとエラー（429）になるだけで、請求は発生しません。
- 無料枠では、送った写真や内容がGoogleのサービス改善に使われる場合があります。気になる場合は有料枠（請求先を登録）に切り替えると学習に使われなくなります。
- 無料枠の回数上限は時期やモデルで変わります。AI Studio の「Usage」や料金ページで確認できます。

**キーの管理**

- APIキーはパスワードと同じです。他人に教えない・SNSやGitHubに貼らないでください。
- 漏れたかもしれないときは、AI Studio の「API keys」画面でそのキーを削除し、作り直してください。
- （任意・`AIza…` 形式のキーのみ）Google Cloud コンソール →「APIとサービス」→「認証情報」でそのキーを開き、
  「アプリケーションの制限」を **ウェブサイト** にして `https://<ユーザー名>.github.io/*` を登録すると、
  このアプリ以外からは使えなくなります。

## 4. 使い方

- **撮影して記録**: 撮影 → 自動で解析 → 量や品目を修正 →「保存」
  - 量(g)を変えると、その品目の栄養素が比例して変わります
  - 「×0.5 〜 ×1.5」で全体の量をまとめて調整
  - 「補足」に「ご飯大盛り」「ドレッシングあり」などを書いて「再解析」すると精度が上がります
- **手入力**: 写真なしで記録（AIは使いません）
- **履歴**: 7日/30日のカロリー推移、1日平均、体重グラフ
- **設定**: 目標値（「目安を計算する」で自動計算可）、バックアップ、CSV書き出し

## 5. データの注意

- 記録はそのスマホの中だけにあります。**機種変更・ブラウザのデータ削除で消えます**。
  「設定」→「バックアップを書き出す」で定期的に保存してください（新しいスマホで「読み込む」と復元できます）。
- 家族それぞれのスマホで、別々に記録されます。

## 6. 更新するとき

GitHubのリポジトリで同じファイル名のファイルを再アップロードします。
スマホ側は、アプリを一度閉じて開き直すと反映されます（記録は消えません）。

## ファイル一覧

```
index.html      画面
style.css       デザイン（ダークモード対応）
app.js          機能（保存・AI呼び出し・集計）
manifest.json   ホーム画面アプリ用の情報
sw.js           オフライン起動用
icons/          アイコン
```

※ 表示される値はAIによる推定で、医療目的のものではありません。
